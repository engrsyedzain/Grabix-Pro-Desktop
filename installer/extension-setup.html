Browser Extension Setup

Grabix Pro is installed. The extension is a separate, one-time step — Chrome and Firefox both require you to add it yourself.

Chrome, Edge or Brave

  1. Open chrome://extensions (Edge: edge://extensions).
  2. Turn on Developer mode — top-right toggle.
  3. Click Load unpacked and select the folder above.
  4. Copy the ID shown on the new extension's card.
  5. In Grabix Pro, go to Settings → Browser Extension, paste the ID, and click Register Host.
Step 5 is not optional. Chrome only lets the extension talk to Grabix Pro if the app registers your specific extension ID. Skip it and the popup will say “Disconnected”.

Firefox

  1. Open about:debugging#/runtime/this-firefox.
  2. Click Load Temporary Add-on….
  3. Select manifest.json inside the folder above.
This lasts until you close Firefox. Firefox only installs add-ons permanently once they are signed by Mozilla, and it removed installer-based (“sideloaded”) add-ons in version 74. A permanent install needs a signed .xpi — see sign_extension.ps1 in the repo. No registration step is needed here; Firefox's host is already set up.
Trouble connecting? Open Grabix Pro → Settings → Browser Extension.
