Chrome, Edge or Brave

  1. Open chrome://extensions (Edge: edge://extensions).
  2. Turn on Developer mode — top-right toggle.
  3. Click Load unpacked and select the folder above.
  4. Copy the ID shown on the new extension's card.
  5. In Grabix Pro, go to Settings → Browser Extension, paste the ID, and click Register Host.
Step 5 is not optional. Chrome only lets the extension talk to Grabix Pro if the app registers your specific extension ID. Skip it and the popup will say “Disconnected”.

Firefox

  2. Click the gear icon ⚙ near the top right → Install Add-on From File…

  4. Click Add when Firefox asks to confirm.
Nothing else to do. This add-on is signed by Mozilla, so it installs permanently and survives a restart. Firefox needs no Extension ID — unlike Chrome, its connection to Grabix Pro is already set up.
Trouble connecting? Open Grabix Pro → Settings → Browser Extension.
